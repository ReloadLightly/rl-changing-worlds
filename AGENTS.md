# Project working agreements

This repository uses small, readable Python, NumPy, and Matplotlib experiments
to learn reinforcement learning through Sutton and Barto, second edition.

- Prioritize running experiments and interpreting measured results. Keep
  scientific sanity checks brief; avoid elaborate frameworks, test suites,
  or infrastructure unless requested.
- Update the README with experimental results, uncertainty, interpretation,
  and reproduction commands when completing experimental changes. Distinguish
  measured findings from hypotheses and label our extensions clearly.
- Save the relevant figures, compact numerical results, configuration, seeds,
  and runtime. Preserve attribution and license notices for reused code.
- The user has authorized committing and pushing completed changes for
  subsequent work in this project. Commit the completed work and push it to
  the connected GitHub repository; do not stop at an uncommitted local change.
  Verify that the push succeeded and report any concrete blocker.
